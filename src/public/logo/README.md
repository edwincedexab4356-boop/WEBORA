# Carpeta de Logo D.E.K NOVACORE

Esta carpeta (`src/public/logo/`) ha sido creada para que montes directamente el logo de tu marca.

### Cómo montar tu propio logo:
1. Coloca tu archivo en esta carpeta (`src/public/logo/logo.svg` o `src/public/logo/logo.png` / `logo.webp`).
2. También puedes colocar una copia en `/public/logo/logo.svg` para acceso estático directo.
3. El componente `WeboraLogo.tsx` cargará automáticamente tu logotipo personalizado o el vector integrado de alta fidelidad.

### Identidad visual configurada:
- **Colores principales:** Negro carbón (`#050608` / `#0B0D12`), Blanco (`#FFFFFF`) y Azul Eléctrico (`#0066FF` / `#00D2FF`).
- **Logo:** Monograma D.E.K con NOVACORE debajo.
- **Descriptor:** DIGITAL SOLUTIONS.
- **Estilo:** Tecnológico, minimalista y premium.
